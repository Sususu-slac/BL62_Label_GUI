# Light / Dark

Use the button at the upper right. In Dark mode it says **Switch to Light**; in
Light mode it says **Switch to Dark**. Switching is immediate and each GUI remembers
its own selection. New installations default to Dark.

Light mode uses blue buttons and selected controls. Dark mode retains the
application's original green accents. Dialogs, menus, lists, logs, progress bars
and charts follow the theme. Image pixels, masks, annotations, histogram settings,
training values, conversations and drafts are preserved. Switching a theme does
not load or restart a scientific model or the language model.

The Label histogram, Fine-tune metrics and MomoBot chat/Telegram settings have
matching Light displays. Phone pairing QR codes retain black and white.

Theme preferences are separate for each application. Scientific environments and
the shared checkpoint locations are unchanged.
